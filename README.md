# tacita · sitio web

Sitio de **tacita**, un café de especialidad ficticio en Chacarita (CABA), con estante (café en grano, libros y merch), carta y reserva del espacio para eventos.

Proyecto integrador de Contenidos y Creatividad I · Universidad de Palermo · 2026 · Wanda Raitelli.

## Cómo está hecho

- **HTML, CSS y JavaScript**, sin frameworks ni librerías.
- `css/estilos.css`: los colores, espacios, radios y estilos de texto son las mismas variables del sistema visual de Figma.
- `js/main.js`: menú mobile, filtros del estante, página de producto, carrito (se guarda en el navegador con `localStorage`), checkout y formularios.
- Diseño responsive: desktop (1440 px) y mobile (390 px), con un corte en 900 px.
- Tipografías de Google Fonts: Fraunces y DM Sans.
